# Thought Stream

A real-time sticky note wall built with **Vite** and **Firebase**.

## Features
- 📝 Post sticky notes in real-time
- 🎨 Choose your note colour and font
- 👀 See everyone's thoughts update live
- 🔥 Powered by Firebase Firestore

## Tech Stack
- Vanilla JavaScript + Vite
- Firebase Firestore (real-time database)
- Firebase Hosting

## Run Locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
firebase deploy
```
